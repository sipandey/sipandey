`Node.js` · `CLI` · `Git Hooks` · `GitHub Actions` · `Agent Governance`

#### 🔎 [Revelio](https://www.npmjs.com/package/@revelio-tools/revelio) · [VS Code Extension](https://marketplace.visualstudio.com/items?itemName=sipandey.revelio-vscode)

`Node.js` · `AST` · `SQLite` · `MCP` · `VS Code` · `D3.js`
